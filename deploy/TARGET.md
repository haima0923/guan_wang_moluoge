## 部署接入

尚未取得 SSH 登录用户名或登录密钥，未执行任何远端修改。接入后先检查现有 Nginx、站点配置、容器运行时、磁盘容量和端口占用，再部署应用。

当前服务器已经运行 Nginx，优先复用它添加 ma.barsan.com.cn 虚拟主机。`nginx.ma.barsan.com.cn.conf` 是仅用于证书申请和内部验收的 HTTP 站点模板，不能作为最终 HTTPS 配置。证书签发后再配置 443、HTTP 跳转和安全登录验收。

应用模板中的 3000 端口须先确认未被占用。新增站点配置前备份现有配置，验证通过后再重新加载；保留主域名服务。

Alibaba Cloud Linux 4 的容器安装方式按阿里云官方文档处理；先检查已有 Docker/Moby 和 Compose，不直接卸载现有容器组件。
